# ⚙️ How It Works

The website is built using a modular architecture.

### HTML

- Defines the website structure.
- Contains all portfolio sections.
- Links CSS and JavaScript files.

### CSS

Styles are divided into multiple files.

| File | Purpose |
|-------|----------|
| Common.css | Global styles and theme |
| Navbar.css | Navigation styling |
| Home.css | Hero section |
| About.css | About section |
| Contact.css | Contact page |

This makes the project clean and easy to maintain.

### JavaScript

JavaScript is used for:

- Navigation functionality
- Interactive effects
- Smooth user experience
